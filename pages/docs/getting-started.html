    Memulai

    Simple Admin adalah situs statis: HTML, CSS, dan JavaScript biasa di atas Bootstrap 5.3. Tidak ada build, tidak ada npm. Panduan ini menjelaskan cara menjalankan, menambah halaman, dan menyesuaikannya untuk proyek Anda.

    • Menjalankan
    • Struktur
    • Halaman baru
    • Menu
    • Warna & brand
    • Data dari API

    1. Menjalankan

    Unduh ZIP dari halaman Releases di GitHub atau clone repositorinya, lalu jalankan server statis apa saja di folder proyek. Membuka index.html langsung dari file juga bisa.

    Alternatif: ekstensi Live Server di VS Code, atau npx serve. Bootstrap, SweetAlert2, dan font dimuat dari CDN, jadi butuh koneksi internet.

    2. Struktur folder

    Semua gaya ada di satu file CSS. JavaScript dibagi menjadi skrip bersama dan skrip per halaman.

    Urutan skrip di halaman aplikasi: Bootstrap → SweetAlert2 → common.js → nav.js → shell.js → data.js (jika perlu) → skrip halaman.

    3. Menambah halaman

    1. Salin pages/blank.html menjadi file baru, misalnya pages/categories.html.
    2. Ganti isi <title>, breadcrumb, dan judul halaman.
    3. Tulis isi halaman di dalam <div class="sa-page"> memakai panel dan komponen dari UI Toolkit.
    4. Daftarkan halaman di menu (langkah 4). Menu aktif ditandai otomatis.
    5. Jika butuh logika sendiri, buat assets/js/pages/categories.js dan muat paling akhir.

    4. Mengubah menu

    Seluruh sidebar diatur di assets/js/nav.js. href ditulis relatif terhadap folder proyek, jadi sama untuk halaman di mana pun. Item dengan children menjadi submenu.

    Ikon yang tersedia ada di objek saIcons di file yang sama. Kartu penyimpanan di bawah sidebar diatur lewat saSidebarCard; isi null untuk menyembunyikannya.

    5. Mengganti warna

    Semua warna adalah variabel CSS di awal assets/css/style.css: blok :root untuk mode terang, [data-bs-theme="dark"] untuk mode gelap. Komponen Bootstrap ikut berubah karena --bs-primary diarahkan ke aksen.

    Setelah mengganti aksen, periksa kontras teks di atasnya minimal 4,5:1 (misalnya dengan WebAIM Contrast Checker). Ubah --sa-on-accent jika teks di tombol utama sulit dibaca. Daftar lengkap token ada di docs/design-system.md.
