Plugin

Tabel data

Modul assets/js/datatable.js mengubah array data menjadi tabel dengan sort kolom, paginasi, pencarian, pilih banyak baris, dan ekspor CSV. JavaScript murni, tanpa jQuery atau library lain. Halaman Pesanan memakai modul ini.

  • Contoh
  • Memasang
  • Opsi kolom
  • Opsi tabel
  • Method

Contoh: daftar produk

Klik judul kolom untuk mengurutkan, centang baris untuk memunculkan aksi massal, lalu coba "Ekspor terpilih". Data dari products di data.js.

Produk

Memasang

Siapkan satu elemen kosong sebagai wadah, muat datatable.js setelah common.js, lalu panggil saDataTable(). Header, isi, aksi massal, dan paginasi dibuat otomatis.

Opsi kolom

Setiap item di columns.

OpsiKeterangan
keyNama properti data. Dipakai untuk isi sel, sort, dan CSV bila opsi lain tidak diisi.
labelTeks header kolom.
align: "end"Rata kanan, untuk angka dan uang.
render(row)HTML isi sel. Teks dari data wajib dibungkus escapeHtml().
sortValue(row)Nilai pembanding saat sort, misalnya tanggal dalam format ISO.
csv(row)Nilai di file CSV, misalnya label status alih-alih kodenya.
sortable: falseMatikan sort untuk kolom ini.
classNameKelas tambahan untuk setiap <td>.

Opsi tabel

OpsiBawaanKeterangan
rows[]Array data.
columns[]Daftar kolom (lihat di atas).
search(row)–Teks yang dicocokkan dengan setQuery().
filter(row)–Filter tambahan, misalnya tab status. Panggil refresh() setelah kondisinya berubah.
sortnullUrutan awal, misalnya { key: "id", dir: "desc" }.
pageSize, pageSizes10, [5, 10, 25]Jumlah baris per halaman dan pilihannya.
selectablefalseTampilkan kotak centang dan bilah aksi massal.
rowId(row)indeksID unik baris, agar pilihan tetap tersimpan saat pindah halaman.
bulkActions[]Tombol aksi massal: { text, action(rows, table) }.
csvName, csvSeparator"data.csv", ","Nama file dan pemisah CSV. Pakai ";" jika Excel Anda berbahasa Indonesia.
label, empty–Nama tabel untuk pembaca layar dan teks saat tidak ada data.

Method

saDataTable() mengembalikan objek untuk mengendalikan tabel dari luar.
