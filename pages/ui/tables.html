    UI Toolkit / Komponen

    Tabel

    Tabel memakai table sa-table di dalam panel. Header kecil berhuruf kapital, angka rata kanan, dan setiap tabel dibungkus table-responsive agar bisa digeser di HP.

    • Tabel dasar
    • Kolom pengguna
    • Keadaan kosong
    • Dari data + pencarian

    Tabel dasar

    Kolom angka memakai text-end sa-num agar rata kanan dan sejajar. ID memakai sa-id, status memakai sa-status.

    Keadaan kosong

    Saat filter atau pencarian tidak menemukan apa pun, tampilkan satu baris sa-empty selebar tabel. Helper emptyRow(kolom, teks) di common.js membuatnya.

    ProdukKategoriStok
    Produk tidak ditemukan

    Dari data + pencarian

    Pola yang dipakai semua halaman daftar: data di array, fungsi render() membangun baris, dan pencarian memanggil render ulang. Coba ketik "band" di kolom pencarian.

    Pelanggan

    PelangganKotaPesanan
    Selalu bungkus teks dari data dengan escapeHtml() sebelum dimasukkan ke innerHTML, terutama jika datanya berasal dari API atau masukan pengguna.
