# Simple Admin v1.1.0

Template kini menjelaskan dirinya sendiri: ada bagian **UI Toolkit** berisi contoh komponen yang bisa langsung disalin, panduan **Memulai** di dalam template, dan menu yang cukup diubah di satu file.

## Yang baru

### Menu dari satu konfigurasi

Seluruh sidebar (nama brand, grup, item, submenu, badge, ikon, dan kartu bawah) sekarang diatur di `assets/js/nav.js`. Tidak perlu lagi mengedit tujuh file HTML untuk menambah satu menu. Menu aktif dan submenu yang terbuka ditentukan otomatis dari alamat halaman.

```js
{ text: "Kategori", href: "pages/categories.html", icon: "box" }
```

### UI Toolkit

Lima halaman dokumentasi interaktif di `pages/ui/`:

- **Tombol**: utama/sekunder, dengan ikon, ukuran, tombol ikon, segmen, memuat, toast dan konfirmasi
- **Form**: input, select, checkbox/radio/saklar, input group, validasi, form dalam panel
- **Tabel**: tabel dasar, kolom pengguna, keadaan kosong, dan tabel dari data dengan pencarian
- **Status & badge**: status pill, badge hitungan, perubahan KPI, avatar, progress
- **Modal & alert**: alert di halaman, toast, dialog konfirmasi, modal form

Setiap contoh menampilkan preview langsung dan kode HTML siap salin. Kodenya diambil otomatis dari preview, jadi selalu sama dengan yang tampil.

### Panduan dan halaman kosong

- **Panduan › Memulai** menjelaskan cara menjalankan, struktur folder, menambah halaman, mengubah menu, mengganti warna, dan mengambil data dari API.
- **Halaman kosong** (`pages/blank.html`) siap disalin sebagai titik awal halaman baru.

### Komponen dan helper baru

- `.sa-alert` (info, success, warning, danger), `.sa-modal`, dan `.sa-badge`
- `escapeHtml()` di `common.js` untuk menampilkan data dari API dengan aman

## Perubahan

- Markup sidebar dihapus dari setiap file HTML. Jika Anda sudah mengubah menu di v1.0.0, pindahkan perubahan itu ke `assets/js/nav.js`.
- Halaman aplikasi sekarang memuat `nav.js` sebelum `shell.js`.
- Badge menu memakai `.sa-badge` agar teksnya kontras di mode gelap.

## Upgrade dari v1.0.0

1. Salin folder `assets/` yang baru.
2. Di setiap halaman aplikasi Anda, ganti seluruh `<aside class="sa-sidebar">…</aside>` dengan:
   ```html
   <aside class="sa-sidebar offcanvas-lg offcanvas-start" tabindex="-1" id="saSidebar" aria-labelledby="saSidebarLabel"></aside>
   ```
3. Tambahkan `<script src="assets/js/nav.js"></script>` tepat sebelum `shell.js` (sesuaikan `../` dengan kedalaman folder).
4. Daftarkan menu Anda di `assets/js/nav.js`.
