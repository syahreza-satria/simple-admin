# Simple Admin v1.2.0

Kerangka halaman kini sepenuhnya diatur dari satu file, semua ikon memakai Bootstrap Icons, dan grafik memakai Chart.js yang warnanya ikut tema.

## Yang baru

### Topbar dari konfigurasi

Seperti sidebar di v1.1.0, topbar sekarang dirender dari `assets/js/nav.js`. Nama pengguna, peran, isi menu akun, dan teks kolom pencarian cukup diubah di satu tempat:

```js
const saUser = { name: "Satria Eza", role: "Administrator" };
const saAccountMenu = [
  { text: "Profil saya", href: "pages/settings.html" },
  { divider: true },
  { text: "Keluar", logout: true },
];
```

Setiap halaman aplikasi kini hanya berisi `<aside id="saSidebar">` dan `<header id="saTopbar">` yang kosong. Tidak ada lagi markup kerangka yang perlu disalin ke setiap file.

### Bootstrap Icons

Semua ikon memakai [Bootstrap Icons](https://icons.getbootstrap.com/) 1.11.3. Pilih ikon dari katalognya, lalu tulis:

```html
<i class="bi bi-house" aria-hidden="true"></i>
```

Di `nav.js`, cukup `icon: "house"`.

### Grafik dengan Chart.js

- Grafik pendapatan Dashboard kini memakai Chart.js 4.4.6.
- Halaman Laporan mendapat grafik donat penjualan per kategori dan grafik batang metode pembayaran.
- Halaman baru **Plugin › Grafik** berisi contoh garis, batang, dan donat yang bisa langsung disalin.

Helper `saChart()` di `assets/js/charts.js` mengambil warna dari token tema, menggambar ulang grafik saat mode gelap diaktifkan, mematikan animasi saat *reduce motion* aktif, dan memformat angka gaya Indonesia (1.400).

```js
saChart(document.getElementById("myChart"), (c) => ({
  type: "bar",
  data: { labels: ["Sen", "Sel"], datasets: [{ data: [42, 38], backgroundColor: c.accent }] },
}));
```

## Perubahan lain

- Data grafik dipindah ke `assets/js/data.js` (`revenue`, `salesByCategory`, `paymentMethods`).
- Token warna kategori grafik baru: `--sa-chart-1` sampai `--sa-chart-5`.
- Menu "Keluar" memakai warna token agar kontras di mode gelap.

## Upgrade dari v1.1.0

1. Salin folder `assets/` yang baru.
2. Tambahkan Bootstrap Icons di `<head>` setiap halaman, setelah CSS Bootstrap:
   ```html
   <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" />
   ```
3. Di setiap halaman aplikasi, ganti seluruh `<header class="sa-topbar">…</header>` dengan:
   ```html
   <header class="sa-topbar" id="saTopbar"></header>
   ```
4. Di `nav.js`, ganti nama ikon lama dengan nama Bootstrap Icons (`home` → `house`, `user` → `person`, `alert` → `exclamation-circle`, `file` → `file-earmark`).
5. Di halaman bergrafik, muat `https://cdn.jsdelivr.net/npm/chart.js@4.4.6/dist/chart.umd.js` setelah SweetAlert2 dan `assets/js/charts.js` setelah `data.js`.
