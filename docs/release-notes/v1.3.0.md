# Simple Admin v1.3.0

Tabel data tanpa library, invoice siap cetak, dan halaman error yang lengkap.

## Yang baru

### Tabel data

Modul baru `assets/js/datatable.js` mengubah array data menjadi tabel lengkap tanpa jQuery atau DataTables:

- Sort kolom dengan klik atau keyboard
- Paginasi dengan pilihan 5, 10, atau 25 baris
- Pencarian dan filter dari luar (misalnya tab status)
- Pilih banyak baris dengan aksi massal
- Ekspor CSV untuk semua baris atau hanya yang dipilih

```js
const table = saDataTable(document.getElementById("myTable"), {
  rows: allOrders,
  columns: [
    { key: "id", label: "No. Pesanan" },
    { key: "total", label: "Total", align: "end", render: (o) => rupiah(o.total) },
  ],
  pageSize: 5,
  selectable: true,
  csvName: "pesanan.csv",
});
```

Halaman **Pesanan** sekarang memakai modul ini, lengkap dengan aksi massal "Tandai lunas" dan tombol "Ekspor CSV" yang benar-benar mengunduh file. Dokumentasi dan contohnya ada di **Plugin › Tabel data**.

### Detail pesanan dan invoice

Klik nomor pesanan di Dashboard atau Pesanan untuk membuka `pages/order-detail.html?id=…`:

- Invoice berisi item, ongkir, total, alamat, dan kurir
- Garis waktu status pesanan dan aksi yang sesuai (tandai lunas, salin resi, kirim ulang tautan pembayaran)
- Tombol **Cetak invoice** yang hanya mencetak invoice, tanpa sidebar dan topbar, selalu dalam mode terang

### Halaman error

Selain 404, kini ada **500 Kesalahan server** dan **Maintenance**, dikelompokkan di menu Halaman › Error.

## Perubahan lain

- Item menu bisa ikut aktif di halaman turunan lewat properti `match` di `nav.js`.
- Data rincian pesanan (`orderDetails`) ditambahkan ke `data.js`.

## Upgrade dari v1.2.0

1. Salin folder `assets/` dan file baru di `pages/` (`order-detail.html`, `error-500.html`, `maintenance.html`, `plugins/datatable.html`).
2. Untuk memakai tabel data di halaman Anda, muat `assets/js/datatable.js` setelah `data.js`, lalu panggil `saDataTable()`.
