# Simple Admin v1.0.0

Rilis pertama Simple Admin: template dashboard admin berbahasa Indonesia dengan HTML, CSS, dan JavaScript murni di atas Bootstrap 5.3.3. Tanpa build tool. Unduh, ekstrak, lalu buka `index.html` di browser.

## Isi rilis

- **7 halaman aplikasi**: Dashboard, Pesanan, Produk, Pelanggan, Laporan, Pengguna & Akses, dan Pengaturan, dengan data contoh toko fiktif "Toko Satria".
- **3 halaman auth**: Masuk, Daftar, dan Lupa Kata Sandi dengan validasi form, meter kekuatan kata sandi, dan tombol login Google, GitHub, Microsoft (simulasi).
- **Halaman 404** yang menampilkan alamat yang dicari dan pintasan ke halaman populer.
- **Mode gelap** yang mengikuti pengaturan sistem, tersimpan di browser, dan tidak berkedip saat dimuat.
- **Grafik pendapatan SVG** tanpa library, dengan rentang 6 atau 12 bulan.
- **Tabel interaktif** dengan filter dan pencarian.
- **Notifikasi**, toast, dan dialog konfirmasi (SweetAlert2) yang mengikuti tema.
- **Responsif**: sidebar menjadi offcanvas di layar kecil.
- **Ramah aksesibilitas**: fokus keyboard terlihat, label ARIA, dan animasi yang mati saat *reduce motion* aktif.
- **Mudah dikustomisasi**: semua warna adalah variabel CSS di awal `assets/css/style.css`.

## Mulai

```bash
python -m http.server 8000
# buka http://localhost:8000
```

Panduan lengkap ada di [README.md](https://github.com/syahreza-satria/simple-admin/blob/v1.0.0/README.md). Token dan komponen visual dijelaskan di [docs/design-system.md](https://github.com/syahreza-satria/simple-admin/blob/v1.0.0/docs/design-system.md).

## Dependensi (via CDN)

- Bootstrap 5.3.3
- SweetAlert2 11.14.5
- Plus Jakarta Sans dan JetBrains Mono (Google Fonts)

## Keterbatasan yang diketahui

- Belum ada backend atau penyimpanan. Perubahan data hilang saat halaman dimuat ulang.
- Halaman auth hanya simulasi: login apa pun berhasil, login sosial belum terhubung ke OAuth, dan halaman aplikasi tidak dijaga.
- `404.html` memakai path relatif dari root, jadi aset hanya termuat benar untuk URL salah di tingkat root.
- Sidebar dan topbar ditulis ulang di setiap file HTML, jadi mengubah menu berarti mengedit ketujuh file.
- Pencarian global di topbar belum mencari apa pun.
- Halaman Laporan dan Pengaturan masih statis.
- Tombol Ekspor, Unduh PDF, dan Undang Pengguna hanya menampilkan toast.
- Membutuhkan internet karena aset dimuat dari CDN.

Sebelum memakai data sungguhan, baca bagian "Hal yang perlu diperhatikan" di [SECURITY.md](https://github.com/syahreza-satria/simple-admin/blob/v1.0.0/SECURITY.md).
